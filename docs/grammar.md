# Формальна граматика мови SIPL

Граматика реалізує синтаксис імперативної мови **SIPL** (Practical Work 1). Будь-яка коректна програма має вигляд `begin S end` і підтримує присвоювання, послідовне виконання, розгалуження, цикли, вкладені блоки та порожній оператор `skip`.

Машиночитна граматика у форматі Lark міститься у файлі [`grammar/sipl.lark`](../grammar/sipl.lark).

## Синтаксис (EBNF)

```ebnf
program     = "begin", statement, "end" ;
statement   = atom | atom, ";", atom, { ";", atom } ;
atom        = assignment | conditional | loop | block | "skip" ;

assignment  = identifier, ":=", arithmetic ;
conditional = "if", boolean, "then", atom, "else", atom ;
loop        = "while", boolean, "do", atom ;
block       = "begin", statement, "end" ;

arithmetic  = number | identifier
            | arithmetic, "+", arithmetic
            | arithmetic, "-", arithmetic
            | arithmetic, "*", arithmetic
            | "(", arithmetic, ")" ;

boolean     = arithmetic, "=", arithmetic
            | arithmetic, ">", arithmetic
            | boolean, "∨", boolean
            | "¬", boolean
            | "(", boolean, ")" ;
```

## Лексичні правила

* **Ідентифікатори (`NAME`):** починаються з латинської літери або символу підкреслення (`[A-Za-z_]`) і продовжуються літерами, цифрами або підкресленнями (`[A-Za-z0-9_]*`). Регістр символів має значення (`X` та `x` — різні змінні).
* **Цілі числа (`NUMBER`):** десяткові цілі числа, включно з від'ємними (`-12`, `0`, `42`). Незначущі нулі на початку заборонені (наприклад, `01` викликає синтаксичну помилку).
* **Ключові слова:** `begin`, `end`, `if`, `then`, `else`, `while`, `do`, `skip`.
* **Оператори та роздільники:** `:=`, `;`, `+`, `-`, `*`, `=`, `>`, `∨`, `¬`, `(`, `)`.
* **Пробільні символи:** пробіли, табуляції та переноси рядків ігноруються й використовуються лише для розділення токенів.

## Пріоритети операцій та асоціативність

| Пріоритет | Оператори | Опис | Асоціативність |
| :---: | :---: | :--- | :--- |
| **1 (найвищий)** | `( ... )` | Дужки для групування виразів | — |
| **2** | `*` | Арифметичне множення | Ліва |
| **3** | `+`, `-` | Арифметичне додавання та віднімання | Ліва |
| **4** | `=`, `>` | Порівняння арифметичних виразів | Неасоціативні |
| **5** | `¬` | Логічне заперечення | Права (унарна) |
| **6 (найнижчий)** | `∨` | Логічне «АБО» (диз'юнкція) | Ліва |

## Правило групування операторів

Гілки умовного оператора (`then ... else ...`) та тіло циклу (`while ... do ...`) приймають рівно один атомарний оператор (`atom`). Щоб виконати послідовність операторів усередині умови чи циклу, її обов'язково потрібно обгорнути у блок `begin ... end`:

```sipl
begin
    while Y > 0 do
    begin
        R := R * X;
        Y := Y - 1
    end
end
```
