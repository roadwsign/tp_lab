# Формат Conformance Suite

Еталонний набір тестів зберігається у файлі [`tests/conformance.json`](../tests/conformance.json) у кодуванні **UTF-8**. Він містить версію формату (`format_version: 1`) та масив тестових сценаріїв `cases` (26 перевірок).

## Структура тестового сценарію

Кожен елемент масиву `cases` описується такими полями:

| Поле | Тип | Обов'язковість | Опис |
| :--- | :--- | :---: | :--- |
| `id` | `string` | Так | Унікальний ідентифікатор тесту (наприклад, `positive-01`, `negative-05`). |
| `source` | `string` | Так | Вихідний код програми мовою SIPL. |
| `valid` | `boolean` | Так | Очікувана синтаксична коректність (`true` — валідна програма, `false` — очікується помилка). |
| `expected_ast` | `object` | Для `valid: true` | Повна еталонна структура AST із позиціями `span`. |
| `expected_error` | `string` | Для `valid: false` | Очікувана категорія помилки (`"syntax"`). |
| `execution` | `boolean` | Ні | Якщо `true`, програма додатково виконується в інтерпретаторі. |
| `initial_state` | `object` | Ні | Початковий стан змінних перед запуском інтерпретатора. |
| `expected_state` | `object` | Для `execution: true` | Очікуваний фінальний стан змінних після виконання програми. |

## Запуск перевірки

Набір тестів запускається як через `pytest` (файл `tests/test_conformance.py`), так і автономним скриптом без зовнішніх тестових залежностей:

```bash
python tests/run_conformance.py
```

Скрипт перевіряє прийняття коректних програм, відхилення некоректних конструкцій, точний збіг побудованого AST з еталоном та фінальні стани пам'яті інтерпретатора.
